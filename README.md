# Фаза — головоломка по основам электрики

Интерактивный учебник по базовой электрике в формате головоломки. Собирай цепи из выключателей, лампочек и проводов.

> Это обучающая головоломка. Она помогает понять принципы электрики, но не заменяет инструктаж по технике безопасности и не даёт права на электромонтажные работы. Реальные работы выполняются только специалистом с допуском.
